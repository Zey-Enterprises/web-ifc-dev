A multi-item overlay_images array renders a carousel. overlay_interval defaults to 3000 milliseconds and only matters when two or more overlay images exist. focal_point identifies the point in the source image to keep visually important. anchor_point identifies the point in the overlay container where that focal point should land. Both default to "50% 50%". Top-level defaults: header: overlay_image_focal_point: "50% 50%" overlay_image_anchor_point: "50% 50%" Slide-level focal_point and anchor_point override the top-level defaults. If JavaScript is disabled or has not run yet, overlay images still render as centered background-size: cover images. If header.overlay_images is omitted and the automatic overlay resolver finds /assets/images/overlay/.{webp,jpg,png}, this include synthesizes one internal slide from that image. If no overlay image exists, header.overlay_color and header.overlay_filter can still render a color/filter-only overlay. is determined from page.path by: 1. removing the file extension 2. splitting the remaining path on "/" 3. removing a single leading "_" from each path segment 4. joining the normalized segments with "_" Examples: - faq.md -> faq - about.md -> about - _resources/articles/calorie-balance-still-governs-body-composition.md -> resources_articles_calorie-balance-still-governs-body-composition overlay_title_width and mobile_overlay_title_width accept any valid CSS max-width value, for example: - 100% - 50% - 12ch - 42rem - 300px If overlay_title_width is omitted, overlay titles use 100% of the overlay wrapper.
