{% comment %} FAQ carousel include. Parameters: - `speed`: absolute scroll speed in CSS pixels per second. Unit suffixes are optional, so `speed=210`, `speed="210"`, and `speed="210px"` all mean 210px/s. The carousel measures the rendered card track in the browser and calculates animation duration from this speed, so adding or removing FAQ entries does not change the visible scroll rate. Default is `125`. - `duration`: legacy fallback loop duration, used only when `speed` is omitted. - `tags`: optional comma-separated tag slugs. Omit to include all FAQ tags. - `domains`: optional comma-separated domain slugs. - `concerns`: optional comma-separated concern slugs. - `limit`: optional maximum number of matching cards. - `excerpt_length`: maximum excerpt characters, including the trailing ellipsis. - `path`: optional FAQ page path. Defaults to `/resources/faq/`. - `id`: optional carousel element ID.
