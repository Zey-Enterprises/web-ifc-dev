{% comment %} Shared internal annotation trigger renderer. Purpose: - Provide the single authoring/rendering contract used by `glossary.html` and `citation.html`. - Keep readable prose clean by rendering only the visible inline trigger plus minimal metadata. Full glossary definitions, citation cards, navigation buttons, and close controls are intentionally NOT rendered inside paragraphs. - Client-side JavaScript reads the metadata here and hydrates the shared global popover layer from `window.IFC_ANNOTATIONS`. Expected inputs from wrapper includes: - `kind`: required. Normalized variant name, typically `glossary` or `citation`. - `trigger_html`: required for glossary or non-numbered triggers. Safe inline HTML. - `extra_html`: optional one-off appended popover content. Stored as escaped metadata and rendered by `annotations.js` only when the popover opens. - `class`: optional extra class names added to the root trigger. - `aria_label`: optional accessible label for the inline trigger. - `style`: optional rendering-style metadata, eg `site` or `chicago`. - `entry_id`: required for glossary triggers. Looks up `window.IFC_ANNOTATIONS.glossary[entry_id]`. - `source_id`: optional canonical citation source ID. - `citation_label`: optional page-local citation label. Used for visible citation markers and, when `source_id` is absent, citation-map resolution. Example internal use: - `{% include _annotation.html kind="glossary" trigger_html=trigger_html entry_id=include.id %}` - `{% include _annotation.html kind="citation" source_id=source_id citation_label=citation_label %}` Notes: - The root element is also the trigger (`data-annotation-trigger`).
